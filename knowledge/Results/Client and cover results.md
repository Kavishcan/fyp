# Client and cover results

Real MCP demonstration: three rounds, one real and two cover; each node receives the same three-point/231-byte request shape. Tests exercise local planning, role permissions, shared dispatch and budget charging.

Later scheduler correction uses a single monotonic run and defers local generation until its network schedule ends. Old demonstration sizes are not complete transport accounting or proof that slow nodes preserve timing.
