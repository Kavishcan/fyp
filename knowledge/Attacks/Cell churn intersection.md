# Cell churn intersection

In the audit, changing registry membership rebuilt cells; one join moved eight of sixteen nodes and intersections could narrow an anonymity set to one.

This remains a limitation of earlier cell routing. Blind all-node operation avoids that cell construction but federation membership changes still need a separate policy.

See [[Anonymity cells]], [[Threat model]].
