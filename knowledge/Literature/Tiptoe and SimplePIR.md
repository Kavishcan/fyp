# Tiptoe and SimplePIR

Primary paper link for Tiptoe: [Private Web Search with Tiptoe](https://doi.org/10.1145/3600006.3613134).

Private search/PIR demonstrates established private-access systems and offline/online cost trade-offs. SimplePIR (Henzinger et al., USENIX Security 2023) is a different work from Tiptoe. Since docs/55 the prototype **uses SimplePIR** (numpy implementation, the paper's LWE parameters) to fetch blind-unlock envelopes for large hospitals ([[PIR tier]]); it does not implement Tiptoe.

Tiptoe is worksheet P61. Verify a separate primary SimplePIR citation before writing its detailed comparison. See [[Paper register]], [[Reading plan]].
