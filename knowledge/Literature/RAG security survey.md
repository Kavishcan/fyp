# RAG security survey (arXiv 2606.25533)

Treats federated RAG as training-time federation (update leakage, poisoning, Sybil, membership inference). Query and routing-pattern leakage are not in its federated threat list — the gap this thesis fills. Open problem it names: couple retrieval and generation — done on the [[Device]].
