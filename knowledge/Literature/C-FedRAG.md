# C-FedRAG

Primary source: [C-FedRAG](https://arxiv.org/html/2412.13163v1).

Confidential computing protects parts of federated retrieval/generation. The application distributes the query to retrievers and aggregates context within its specified trusted environment; its transport includes mTLS. Do not call this plaintext network broadcast.

Compare trusted execution boundaries with the project's trusted user device. It is prior work for confidential distributed RAG, not an officially executed baseline here. Worksheet record: P11 in [[Paper register]].
