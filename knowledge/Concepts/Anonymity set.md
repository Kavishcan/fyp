# Anonymity set

The set of sources among which the relevant one is hidden. To hide which source matters from an observer of all traffic, the anonymity set must equal the contacted set — the same principle as the PIR lower bound. [[Anonymity cells]]: set = the cell. [[Blind unlock]]: set = every hospital. Cost grows with the set ([[Scaling of blind unlock]]).
