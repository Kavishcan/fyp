# MCP node

The node service publishes profiles and tables and evaluates blinded points with owner-controlled keys. Configured credentials control collections and daily budget. Gated nodes restrict open retrieval.

MCP is an interoperability protocol, not a privacy primitive. Current local/process transport measurements do not establish hardened remote TLS deployment. Node registration and identity provisioning remain important.

See [[Credential gate]], [[Profile signing]], [[Code map]].
