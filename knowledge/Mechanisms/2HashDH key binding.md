# 2HashDH key binding

Envelope keys and lookup tags hash the cluster id together with k·H(c) (F_k(x) = H2(x, k·H1(x)), Jarecki–Kiayias–Krawczyk), so the construction is the one the standard OPRF security proof covers. Added while writing [[Formal leakage]]; changes no measured number.
