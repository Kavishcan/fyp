# Broadcast

Contact every source. Removes [[Access-pattern leakage]] (contact set constant). In text mode (the [[HyFedRAG]]-style design) every hospital reads the question. PSI to all 8 hides both but costs ~198 MB and ~0.8 s per question — the cost [[Blind unlock]] removes. For trusted hospitals (setting A) text broadcast + padding is the simplest pattern defence.
