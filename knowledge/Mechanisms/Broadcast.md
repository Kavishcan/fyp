# Broadcast

Contact every source with the same policy. A fixed contacted-source set carries no per-question source-selection variation. Text broadcast nevertheless exposes the actual query to every source.

Blind unlock uses all-node contact with hidden real/dummy cluster inputs, not raw-query broadcast. Network timing, failures and identity are separate channels.
