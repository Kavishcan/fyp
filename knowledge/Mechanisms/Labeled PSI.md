# Labeled PSI

Private set intersection where the server attaches data ("labels") to items and the client receives the label only for items it holds ([[Chen-Laine-Rindal 2018]]). Here: item = cluster id, label = the cluster's encrypted passages. Used in [[Per-query PSI dispatch]] and, with offline download, in [[Blind unlock]].
