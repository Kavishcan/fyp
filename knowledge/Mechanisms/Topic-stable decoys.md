# Topic-stable decoys

Genuine source + decoys chosen by a topic key, the same every time for a topic. Cuts the [[Source attack]] but **the cover set is a topic fingerprint**: topic inference unchanged (0.496 → 0.495, [[Pattern leak results]]) and worse than no decoys in a session (0.469 → 0.570, [[Session attack]]). Negative result — keep it.
